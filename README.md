# JustNewTab

一款多浏览器可用的新标签页插件，提供书签管理和 TODO 便签功能。

## 功能

- **书签管理** - 在新标签页展示和管理浏览器书签
- **TODO 便签** - 快速记录待办事项和便签

## 技术栈

- Svelte + TypeScript
- Tailwind CSS
- Vite
- webextension-polyfill（跨浏览器兼容）

## 开发

```bash
# 安装依赖
pnpm install

# 开发模式
pnpm dev

# 构建
pnpm build
```
