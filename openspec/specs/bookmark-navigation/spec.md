## 新增需求

### 需求：默认书签导航行为

系统应在用户点击书签时默认在当前标签页中打开。

#### 场景：左键点击书签

- **当**用户左键点击书签
- **则**系统将当前标签页导航到书签 URL

#### 场景：导航反馈

- **当**用户点击书签时
- **则**系统在导航前显示简短的加载指示器

#### 场景：无效 URL 处理

- **当**书签 URL 无效或无法访问
- **则**系统显示错误信息："打开书签失败"

### 需求：键盘修饰键支持

系统应支持键盘修饰键以实现不同的导航行为。

#### 场景：Ctrl+点击（Windows/Linux）

- **当**用户按住 Ctrl 并点击书签
- **则**系统在新标签页中打开书签

#### 场景：Cmd+点击（Mac）

- **当**用户按住 Cmd 并点击书签
- **则**系统在新标签页中打开书签

#### 场景：Shift+点击

- **当**用户按住 Shift 并点击书签
- **则**系统在新窗口中打开书签

#### 场景：中键点击

- **当**用户中键点击书签
- **则**系统在新标签页中打开书签

### 需求：可配置的导航模式

系统应提供设置选项以配置默认的书签导航行为。

#### 场景：导航设置位置

- **当**用户打开设置面板
- **则**系统显示"书签打开模式"设置及其选项

#### 场景：设置选项

- **当**用户查看导航设置时
- **则**系统显示三个选项："当前标签页"、"新标签页"、"新窗口"

#### 场景：默认设置

- **当**用户首次安装扩展
- **则**系统将默认导航模式设置为"当前标签页"

### 需求：保存导航偏好

系统应持久化用户的导航偏好设置。

#### 场景：保存设置

- **当**用户更改导航模式设置
- **则**系统将偏好保存到 localStorage

#### 场景：恢复设置

- **当**用户打开新的浏览器会话
- **则**系统恢复已保存的导航偏好

#### 场景：设置跨工作区同步

- **当**用户更改导航设置
- **则**系统将设置应用到所有工作区

### 需求：导航模式应用

系统应在用户点击书签时应用已配置的导航模式。

#### 场景：当前标签页模式

- **当**导航模式设置为"当前标签页"且用户点击书签
- **则**系统将当前标签页导航到书签 URL

#### 场景：新标签页模式

- **当**导航模式设置为"新标签页"且用户点击书签
- **则**系统打开新标签页并加载书签 URL

#### 场景：新窗口模式

- **当**导航模式设置为"新窗口"且用户点击书签
- **则**系统打开新窗口并加载书签 URL

### 需求：书签悬停预览

系统应在用户悬停在书签上时显示书签 URL。

#### 场景：悬停提示

- **当**用户将鼠标悬停在书签上
- **则**系统以提示框（title 属性）形式显示完整 URL

#### 场景：URL 显示格式

- **当**提示框显示时
- **则**系统显示不带协议的 URL（例如显示 "example.com/path" 而非 "https://example.com/path"）

### 需求：导航历史感知

系统应处理新标签页内的导航行为。

#### 场景：浏览器后退按钮

- **当**用户导航到书签页面后点击浏览器后退按钮
- **则**系统返回新标签页

#### 场景：导航状态保留

- **当**用户返回新标签页时
- **则**系统恢复之前的工作区和滚动位置

### 需求：跨浏览器导航兼容性

系统应在各浏览器中保持一致的导航行为。

#### 场景：Chrome 导航

- **当**在 Chrome 中运行时
- **则**系统通过 webextension-polyfill 使用 chrome.tabs.update() 或 window.location.href

#### 场景：Firefox 导航

- **当**在 Firefox 中运行时
- **则**系统通过 webextension-polyfill 使用 browser.tabs.update() 或 window.location.href

#### 场景：Edge 导航

- **当**在 Edge 中运行时
- **则**系统通过 webextension-polyfill 使用 chrome.tabs.update() 或 window.location.href
