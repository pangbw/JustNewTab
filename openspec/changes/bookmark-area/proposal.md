## Why

当前插件缺少一个可视化的书签管理区域，用户无法快速访问和组织常用书签。需要实现一个功能完整的书签区域，支持分块管理、工作区切换、搜索和自定义配置，提升用户的书签使用效率。

## What Changes

- 新增书签区域组件，替代浏览器默认新标签页
- 实现书签块管理功能，支持创建、编辑、删除书签块
- 添加工作区页签管理，支持多个书签工作区
- 集成搜索功能，支持书签快速搜索
- 实现右键菜单功能，支持创建块和书签
- 添加书签块拖动功能，支持自由调整位置
- 实现书签块的收起/展开功能
- 添加快速配置功能，支持编辑块名称和颜色
- 实现书签区域的响应式布局，适配不同屏幕尺寸
- 新增书签右键快速编辑功能，支持编辑显示内容、URL、描述
- 实现已打开书签的着重显示和快速关闭功能
- 实现书签左键点击默认在当前页面打开（预留新标签页打开配置）

## Capabilities

### New Capabilities

- `bookmark-workspace`: 书签工作区管理，支持多页签切换和工作区创建/删除
- `bookmark-block`: 书签块管理，支持创建、编辑、删除、拖动和收起/展开书签块
- `bookmark-context-menu`: 右键菜单功能，支持创建块、创建书签和默认提示
- `bookmark-search`: 书签搜索功能，支持快速搜索和筛选书签
- `bookmark-quick-config`: 快速配置功能，支持编辑块名称、块颜色等配置
- `bookmark-quick-edit`: 书签右键快速编辑功能，支持编辑显示内容、URL、描述
- `bookmark-open-state`: 书签打开状态检测和显示，支持着重显示已打开书签和快速关闭
- `bookmark-navigation`: 书签导航行为，支持左键点击打开方式配置

### Modified Capabilities

（无）

## Impact

### 代码影响

- 新增书签区域主组件 `BookmarkArea.svelte`
- 新增书签块组件 `BookmarkBlock.svelte`
- 新增工作区页签组件 `WorkspaceTabs.svelte`
- 新增搜索组件 `SearchBox.svelte`
- 新增右键菜单组件 `ContextMenu.svelte`
- 新增快速配置组件 `QuickConfig.svelte`
- 新增书签数据管理 store
- 新增拖拽功能实现
- 新增样式文件

### 依赖影响

- 需要添加拖拽库（如 `svelte-dnd-action` 或原生拖拽 API）
- 需要添加右键菜单库（如 `svelte-context-menu`）
- 可能需要添加颜色选择器组件

### 扩展体积影响

- 预计新增 JavaScript 代码：~50-80KB
- 预计新增 CSS 代码：~10-20KB
- 预计新增图片资源：~5-10KB
- 总体扩展体积增加：~65-110KB

### 多浏览器兼容性

- 使用 `webextension-polyfill` 统一 `chrome` 和 `browser` API
- 书签 API 兼容 Chrome、Edge、Firefox
- 拖拽功能使用标准 HTML5 Drag and Drop API
- 右键菜单使用标准 ContextMenu API
- 搜索功能使用标准书签搜索 API

## 非目标

- 不实现书签同步功能（跨设备同步）
- 不实现书签导入/导出功能
- 不实现书签标签分类功能
- 不实现书签历史记录功能
- 不实现书签分享功能
- 不实现书签高级排序算法（如智能排序）
- 不实现书签统计功能（访问次数等）
- 不实现书签备份/恢复功能
