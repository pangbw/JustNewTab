## Why

当前书签区域的实现代码质量不佳，缺乏与设计规范的一致性。需要彻底重构书签区域，完全丢弃原有代码，基于已建立的设计令牌系统和 UI 样式规范重新实现。同时调整页面布局比例，将书签区域与便签区域的比例从 1:1 改为 3:1，突出书签功能的主要地位。

## What Changes

- **BREAKING**: 完全删除并重写书签区域的所有组件代码
- 修改页面布局比例，书签区域占 75%，便签区域占 25%
- 基于设计令牌系统重新实现所有书签组件样式
- 确保所有组件符合 UI 样式规范（MiMo 风格）
- 重新实现书签块、工作区、搜索、右键菜单等功能组件

## Capabilities

### New Capabilities

（无新增能力，本次变更为重构现有能力）

### Modified Capabilities

- `page-layout`: 修改双栏布局比例为 3:1（书签:便签），更新响应式断点处理
- `bookmark-block`: 重构书签块组件，使用设计令牌系统，优化视觉效果和交互体验
- `bookmark-workspace`: 重构工作区页签组件，统一使用设计令牌样式
- `bookmark-context-menu`: 重构右键菜单组件，使用设计令牌系统
- `bookmark-search`: 重构搜索框组件，使用设计令牌系统
- `bookmark-quick-config`: 重构快速配置卡片，使用设计令牌系统
- `bookmark-quick-edit`: 重构快速编辑卡片，使用设计令牌系统
- `bookmark-open-state`: 重构书签打开状态显示，使用设计令牌系统
- `bookmark-navigation`: 重构书签导航行为，保持功能不变

## Impact

### 代码影响

- **删除**: `src/components/bookmark/` 目录下所有现有组件
- **重写**: 所有书签相关 Svelte 组件
- **修改**: `src/lib/stores/` 中书签相关的 store（如需优化）
- **修改**: 页面主布局组件，调整比例

### 依赖影响

- 无新增依赖
- 可能移除不再需要的旧依赖

### 扩展体积影响

- 预期体积变化：基本持平或略有减少（删除冗余代码）
- 新代码严格遵循设计令牌，减少重复样式定义

### 多浏览器兼容性

- 无额外影响
- 继续使用 webextension-polyfill 统一 API

## 非目标

- 不改变现有功能逻辑（书签块、工作区、搜索等功能保持不变）
- 不添加新的功能特性
- 不修改便签区域的实现
- 不改变设计令牌系统本身
- 不修改浏览器兼容性策略
