## MODIFIED Requirements

### Requirement: 书签区域右键菜单显示

系统应在用户右键点击书签区域时显示右键菜单，使用设计令牌系统。

#### Scenario: 右键点击空白区域

- **WHEN** 用户右键点击书签区域的空白位置
- **THEN** 系统显示包含"创建书签块"和"创建书签"选项的右键菜单
- **AND** 菜单使用设计令牌定义的深色主题样式

#### Scenario: 右键点击书签块

- **WHEN** 用户右键点击书签块
- **THEN** 系统显示包含"编辑书签块"、"删除书签块"、"添加书签"、"折叠/展开"选项的右键菜单
- **AND** 菜单使用设计令牌定义的深色主题样式

#### Scenario: 右键点击书签项

- **WHEN** 用户右键点击书签项
- **THEN** 系统显示包含"编辑书签"、"删除书签"、"在新标签页打开"、"复制 URL"选项的右键菜单
- **AND** 菜单使用设计令牌定义的深色主题样式

### Requirement: 右键菜单定位

系统应在点击位置附近显示右键菜单。

#### Scenario: 菜单在点击位置显示

- **WHEN** 用户在特定位置右键点击
- **THEN** 系统在点击位置显示右键菜单

#### Scenario: 菜单保持在视口内

- **WHEN** 右键菜单会超出视口边界时
- **THEN** 系统调整菜单位置以保持在视口内

### Requirement: 右键菜单项操作

系统应在用户点击右键菜单项时执行相应操作。

#### Scenario: 创建书签块操作

- **WHEN** 用户点击右键菜单中的"创建书签块"
- **THEN** 系统在点击位置创建新的书签块

#### Scenario: 创建书签操作

- **WHEN** 用户点击右键菜单中的"创建书签"
- **THEN** 系统显示输入书签标题和 URL 的对话框

#### Scenario: 编辑书签块操作

- **WHEN** 用户点击右键菜单中的"编辑书签块"
- **THEN** 系统启用书签块名称编辑

#### Scenario: 删除书签块操作

- **WHEN** 用户点击右键菜单中的"删除书签块"
- **THEN** 系统在确认后删除书签块

#### Scenario: 添加书签操作

- **WHEN** 用户点击右键菜单中的"添加书签"
- **THEN** 系统显示向书签块添加书签的对话框

#### Scenario: 编辑书签操作

- **WHEN** 用户点击右键菜单中的"编辑书签"
- **THEN** 系统显示编辑书签标题和 URL 的对话框

#### Scenario: 删除书签操作

- **WHEN** 用户点击右键菜单中的"删除书签"
- **THEN** 系统在确认后删除书签

#### Scenario: 在新标签页打开操作

- **WHEN** 用户点击右键菜单中的"在新标签页打开"
- **THEN** 系统在新的浏览器标签页中打开书签 URL

#### Scenario: 复制 URL 操作

- **WHEN** 用户点击右键菜单中的"复制 URL"
- **THEN** 系统将书签 URL 复制到剪贴板

### Requirement: 右键菜单关闭

系统应在用户点击菜单外部时关闭右键菜单。

#### Scenario: 点击菜单外部

- **WHEN** 用户点击右键菜单外部区域
- **THEN** 系统关闭右键菜单

#### Scenario: 按下 Escape 键

- **WHEN** 用户在右键菜单打开时按下 Escape 键
- **THEN** 系统关闭右键菜单

### Requirement: 无书签块时的默认提示

系统应在书签区域没有书签块时显示默认提示，使用设计令牌系统。

#### Scenario: 空书签区域

- **WHEN** 书签区域没有任何书签块
- **THEN** 系统显示提示信息："右键打开菜单创建书签"
- **AND** 提示信息使用设计令牌定义的辅助文本色（var(--jnt-text-tertiary)）
- **AND** 提示信息使用设计令牌定义的字体大小（var(--jnt-text-base)）

#### Scenario: 创建书签块后提示消失

- **WHEN** 用户创建了书签块
- **THEN** 系统隐藏提示信息

### Requirement: 右键菜单样式

系统应使右键菜单样式与应用主题保持一致，基于设计令牌系统。

#### Scenario: 菜单外观

- **WHEN** 右键菜单显示时
- **THEN** 系统使用设计令牌定义的背景色（var(--jnt-bg-tertiary)）
- **AND** 使用设计令牌定义的边框色（var(--jnt-bg-elevated)）
- **AND** 使用设计令牌定义的圆角（var(--jnt-radius-lg)）
- **AND** 使用设计令牌定义的阴影（var(--jnt-shadow-xl)）
- **AND** 使用设计令牌定义的内边距（var(--jnt-space-1)）

#### Scenario: 菜单项悬停效果

- **WHEN** 用户将鼠标悬停在菜单项上
- **THEN** 系统高亮显示该菜单项
- **AND** 使用设计令牌定义的悬停背景色（var(--jnt-bg-elevated)）

#### Scenario: 菜单项文本样式

- **WHEN** 菜单项显示时
- **THEN** 系统使用设计令牌定义的字体大小（var(--jnt-text-sm)）
- **AND** 使用设计令牌定义的次文本色（var(--jnt-text-secondary)）
- **AND** 使用设计令牌定义的内边距（var(--jnt-space-2) var(--jnt-space-4)）

### Requirement: 右键菜单动画

系统应为右键菜单的出现添加动画效果，使用设计令牌系统。

#### Scenario: 菜单出现动画

- **WHEN** 右键菜单出现时
- **THEN** 系统显示平滑的淡入动画
- **AND** 使用设计令牌定义的过渡时间（var(--jnt-duration-fast)）
- **AND** 使用设计令牌定义的缓动函数（var(--jnt-ease-standard)）

#### Scenario: 菜单关闭动画

- **WHEN** 右键菜单关闭时
- **THEN** 系统显示平滑的淡出动画
- **AND** 使用设计令牌定义的过渡时间（var(--jnt-duration-fast)）
