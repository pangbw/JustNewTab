## MODIFIED Requirements

### 需求：搜索框样式

系统应确保搜索框使用统一的视觉样式。

#### 场景：搜索框外观

- **当**搜索框显示时
- **则**系统使用设计令牌定义的背景色（var(--jnt-bg-tertiary)）
- **且**使用设计令牌定义的圆角（var(--jnt-radius-lg)）
- **且**使用设计令牌定义的内边距（var(--jnt-space-3)）

#### 场景：搜索输入框样式

- **当**搜索输入框显示时
- **则**系统使用透明背景
- **且**使用设计令牌定义的主文本色（var(--jnt-text-primary)）
- **且**使用设计令牌定义的占位文本色（var(--jnt-text-placeholder)）

#### 场景：搜索下拉列表样式

- **当**搜索下拉列表显示时
- **则**系统使用设计令牌定义的背景色（var(--jnt-bg-tertiary)）
- **且**使用设计令牌定义的边框色（var(--jnt-bg-elevated)）
- **且**使用设计令牌定义的圆角（var(--jnt-radius-lg)）
- **且**使用设计令牌定义的阴影（var(--jnt-shadow-xl)）
- **且**使用最大高度和滚动（max-h-64 overflow-y-auto）

#### 场景：搜索结果项样式

- **当**搜索结果项显示时
- **则**系统使用设计令牌定义的字体大小（var(--jnt-text-sm)）
- **且**使用设计令牌定义的次文本色（var(--jnt-text-secondary)）
- **且**使用设计令牌定义的内边距（var(--jnt-space-2) var(--jnt-space-3)）
- **且**悬停时使用设计令牌定义的提升背景色（var(--jnt-bg-elevated)）

#### 场景：搜索结果高亮样式

- **当**搜索结果高亮显示时
- **则**系统使用品牌色背景（var(--jnt-brand-primary)）带透明度
- **且**使用设计令牌定义的主文本色（var(--jnt-text-primary)）

#### 场景：搜索结果计数样式

- **当**搜索结果计数显示时
- **则**系统使用设计令牌定义的字体大小（var(--jnt-text-sm)）
- **且**使用设计令牌定义的辅助文本色（var(--jnt-text-tertiary)）

#### 场景：无搜索结果样式

- **当**无搜索结果显示时
- **则**系统使用设计令牌定义的辅助文本色（var(--jnt-text-tertiary)）
- **且**使用设计令牌定义的字体大小（var(--jnt-text-sm)）
