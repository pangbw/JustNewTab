## Context

JustNewTab 是一款多浏览器新标签页扩展，使用 Svelte + TypeScript + Tailwind CSS 构建。当前书签区域的样式存在一些视觉问题，需要修复以提升用户体验。

**当前状态**:

- 使用 Tailwind CSS 的实用优先方法进行样式设计
- 样式定义在 `src/styles/bookmark-area.css` 和各组件的 Tailwind 类名中
- 深色主题（slate 色系）为主要设计风格

**约束条件**:

- 必须保持 Manifest V2/V3 兼容性
- 不能引入新的 CSS 框架依赖
- 需要保持响应式设计

## Goals / Non-Goals

**Goals:**

- 修复书签区域的视觉样式问题
- 提升深色主题下的可读性和对比度
- 确保响应式布局在不同屏幕尺寸下正常工作
- 统一组件间的视觉一致性

**Non-Goals:**

- 不改变现有功能逻辑
- 不添加新的 UI 组件
- 不重构整体架构
- 不支持亮色主题（当前仅深色主题）

## Decisions

### 1. 样式修复策略

**决策**: 优先使用 Tailwind CSS 类名进行修复，必要时更新 CSS 文件

**理由**:

- 保持与现有代码风格一致
- 利用 Tailwind 的实用优先方法快速修复
- 减少自定义 CSS 的维护负担

**替代方案**:

- 完全重写 CSS 文件：风险较高，可能引入新问题
- 使用 CSS-in-JS：与现有技术栈不符

### 2. 颜色系统调整

**决策**: 基于 slate 色系进行微调，保持深色主题

**理由**:

- slate 色系提供良好的深色主题基础
- 微调比大规模重写更安全
- 保持品牌一致性

**替代方案**:

- 切换到其他色系：可能破坏整体视觉一致性
- 使用 CSS 变量：当前规模不需要

### 3. 响应式断点

**决策**: 使用 Tailwind 默认断点（sm, md, lg, xl）

**理由**:

- 与 Tailwind 生态系统一致
- 覆盖主流设备尺寸
- 减少自定义断点维护

## Risks / Trade-offs

| 风险                         | 影响 | 缓解措施                         |
| ---------------------------- | ---- | -------------------------------- |
| 样式修复可能影响其他组件     | 中   | 逐步修复，每次修复后测试         |
| 深色主题对比度不足           | 低   | 使用 WCAG 对比度检查工具         |
| 响应式布局在某些设备显示异常 | 中   | 使用浏览器开发者工具测试多种尺寸 |
| Tailwind 类名冲突            | 低   | 使用 BEM 命名约定或 scoped 样式  |

## Migration Plan

1. **准备阶段**
   - 备份当前样式文件
   - 创建修复分支

2. **实施阶段**
   - 按组件逐步修复样式
   - 每个修复后进行视觉测试
   - 记录修改内容

3. **验证阶段**
   - 在不同浏览器中测试
   - 检查响应式布局
   - 验证深色主题可读性

4. **回滚策略**
   - 使用 Git 版本控制
   - 每个修复独立提交
   - 可随时回退到任意修复点
