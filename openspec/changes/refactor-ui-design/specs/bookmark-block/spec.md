## MODIFIED Requirements

### 需求：书签块样式一致性

系统应确保所有书签块使用统一的视觉样式。

#### 场景：书签块背景和边框

- **当**书签块显示时
- **则**系统使用设计令牌定义的背景色（var(--jnt-bg-tertiary)）
- **且**使用设计令牌定义的圆角（var(--jnt-radius-xl)）
- **且**使用设计令牌定义的内边距（var(--jnt-space-4)）
- **且**使用设计令牌定义的阴影（var(--jnt-shadow-md)）

#### 场景：书签块悬停效果

- **当**用户将鼠标悬停在书签块上
- **则**系统显示悬停状态，使用设计令牌定义的提升背景色（var(--jnt-bg-elevated)）
- **且**使用设计令牌定义的过渡时间（var(--jnt-duration-normal)）
- **且**使用设计令牌定义的缓动函数（var(--jnt-ease-standard)）

#### 场景：书签块拖拽状态

- **当**用户正在拖拽书签块
- **则**系统显示半透明效果（opacity-50）
- **且**显示缩放效果（scale-95）

#### 场景：书签块拖放目标状态

- **当**用户拖拽书签块到目标位置
- **则**系统显示品牌色边框高亮（使用 var(--jnt-brand-primary)）

#### 场景：书签块标题样式

- **当**书签块标题显示时
- **则**标题使用设计令牌定义的字体大小（var(--jnt-text-lg)）
- **且**标题使用设计令牌定义的字体粗细（var(--jnt-font-semibold)）
- **且**标题使用设计令牌定义的主文本色（var(--jnt-text-primary)）

#### 场景：书签块折叠/展开动画

- **当**用户折叠或展开书签块时
- **则**系统显示平滑的动画过渡效果
- **且**使用设计令牌定义的过渡时间（var(--jnt-duration-normal)）
- **且**使用设计令牌定义的缓动函数（var(--jnt-ease-standard)）

#### 场景：书签块错误提示样式

- **当**书签块显示错误提示时
- **则**错误提示使用设计令牌定义的错误色（var(--jnt-color-error)）
- **且**使用设计令牌定义的字体大小（var(--jnt-text-sm)）
